# LOS201 - Embedded Linux Systems

## LAB-01: Embedded Linux on ARMv7 Cortex-A9

This directory contains the complete build artifacts and configuration files for LAB-01.

### Target platform
- ARMv7-A Cortex-A9
- QEMU vexpress-a9
- Linux Kernel 5.15
- U-Boot 2022.04
- BusyBox 1.35.0

### Main artifacts
- output/zImage
- output/vexpress-v2p-ca9.dtb
- output/initramfs.cpio.gz
- output/u-boot
- output/u-boot.bin
- configs/kernel.config
- configs/busybox.config
- configs/uboot.config
- rootfs/
- scripts/boot_qemu.sh
