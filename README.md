# LOS201 — Embedded Linux Systems

Hands-on Embedded Linux projects covering ARM cross-compilation, Linux boot flow, bootloaders, root filesystems, kernel modules, device drivers, and system integration.

## Projects

| Project | Description | Status |
|---|---|---|
| [LAB 1](./LAB%201/) | Build a complete minimal Embedded Linux system for ARMv7 Cortex-A9 with Linux 5.15, U-Boot, BusyBox, initramfs and QEMU | ✅ Completed |

## Main Topics

- ARMv7-A and Cortex-A9
- Cross-compilation
- Linux Kernel configuration and KBuild
- Device Tree
- U-Boot
- BusyBox
- Root Filesystem
- initramfs
- QEMU system emulation
- Embedded Linux boot debugging
- Kernel modules and device drivers in later labs

## Development Environment

- Linux host
- ARM GNU cross-compiler
- QEMU ARM emulator
- Linux Kernel
- U-Boot
- BusyBox
- GNU Make and shell scripting
